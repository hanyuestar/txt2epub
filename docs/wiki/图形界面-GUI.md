# 图形界面（GUI）使用指南

适合不想敲命令、只想点点鼠标的用户。GUI 是一个 Windows 单文件 exe，**无需安装 Python**，下载双击即可运行。

## 下载与运行

1. 前往 [Releases](https://github.com/hanyuestar/txt2epub/releases) 下载 `txt2epub-gui.exe`；
2. 双击运行（要求 **Windows 64 位**）；
3. 窗口标题为「**txt2epub 转换器**」。

> 若被杀毒软件拦截，请将其加入白名单后重试。exe 为 PyInstaller 单文件打包，偶尔会被误报。

## 主窗口布局

窗口分为四个区域：

1. **① 文件选择区**
   - 「选择文件…」：一次多选多个 `.txt`；
   - 「选择文件夹…」：扫描该目录**顶层**的 `.txt`（**不递归**子目录）；
   - 「清空列表」：清空全部；
   - 右侧显示「已加载 N 个文件」；
   - 列表每行显示文件名、状态（待转换 / 转换中 / 成功 / 失败）和「移除」按钮（转换中不可移除）。
2. **② 输出目录区**：只读输入框 + 「浏览…」按钮，选择转换后 EPUB 的存放目录。
3. **③ 进度区**：进度条 + 状态文字（如「状态: 正在转换 xxx.txt　已处理 2 / 5」）。
4. **底部「确认转换」**：仅当「已加载文件且输出目录有效」时才可点击。

顶部菜单「帮助 → 关于」可查看版本号（v1.0.0）与简介。

## 操作步骤

1. 点「**选择文件…**」多选 TXT，或点「**选择文件夹…**」自动扫描该目录顶层 `.txt`；
2. 在文件列表中，按需点每行「**移除**」剔除不需要的文件；或点「**清空列表**」全部清空；
3. 点「**浏览…**」选择**输出目录**；
4. 确认无误后点底部「**确认转换**」；
5. 等待进度条走完，弹出「**转换完成**」对话框，显示 总计 / 成功 / 失败 统计，失败项附原因清单；
6. 转换后的 `.epub` 生成在你指定的输出目录，文件名与源 TXT **同名**（`源文件.txt → 源文件.epub`）。

## 行为说明

- **后台转换**：转换在独立线程执行，界面不会卡死；进度通过主线程轮询刷新。
- **单文件失败不影响其余**：某个文件失败只会记录在「失败清单」中，其余文件照常转换；失败文件不会产生残缺 epub（原子写入）。
- **默认覆盖**：GUI 默认 `overwrite=True`，重复运行同一批文件会直接重生成（不会整批因“已存在”而失败）。
- **文件夹扫描不递归**：「选择文件夹…」只取目录顶层 `.txt`，不会进入子目录。
- **编码 / 标题 / 封面自动识别**：GUI 暂未暴露高级参数，文件名、作者、简介、封面均走内核自动识别（详见 [章节识别与元数据](章节识别与元数据.md) 与 [编码与兼容性](编码与兼容性.md)）。

## 已知限制（v1）

- 不支持**中途中止**转换；
- 不暴露编码、封面、标题等高级参数（需手动控制请使用 [命令行-CLI](命令行-CLI.md)）；
- 文件夹扫描仅顶层，不含子目录。
