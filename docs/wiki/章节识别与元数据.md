# 章节识别与元数据

## 章节标题识别

内核兼容以下常见标题形式，并据此切分成 EPUB 章节：

- **中文章节**：`第一章 标题`、`第二回 标题`、`第 十二 章 标题`、`012 标题`
- **分卷**：`第一卷 标题`、`【第一卷：标题】`
- **数字编号**：`001 [标题]`、`1. 标题`
- **英文**：`Chapter`、`Book`、`Part`、`Volume` 标题（含罗马数字）
- **特殊章节**：`序章`、`楔子`、`前言`、`终章`、`尾声`、`后记`、`附录`、`番外`

额外处理：

- 自动移除正文前**重复的纯标题目录**；
- 处理抓取内容中的常见 HTML 段落标签（`<p> <br> <div> <h1-6> <li>`）；
- 解码 `&amp;` 等 HTML 实体；
- **不会误判小数和时间戳**为章节标题；
- 当无法可靠判断章节结构时，正文整体保留为**一个 EPUB 章节**，避免把普通段落空行错误拆分。

## 自动提取的元数据

若 TXT 开头（前 200 行）包含以下字段，会自动读取并写入 EPUB 与扉页：

- `书名：` / `书籍名称：`
- `作者：`
- `简介：` / `内容简介：` / `作品简介：` / `文案：` / `内容提要：` / `内容梗概：`
- `字数：` / `总字数：`
- `章节数：` / `章节：`

扉页内容：若指定封面，封面为**第一页**；其后展示**书名、作者、字数、章节数**的扉页。这两页均不计入目录。

## 手动指定元数据

- **CLI**：用 `--title` / `--author` / `--language` / `--description` / `--description-file` / `--cover` 显式覆盖自动识别结果。
- **GUI（v1）**：暂不支持手动指定，统一走自动识别。如需精确控制，请使用 [命令行-CLI](命令行-CLI.md)。
