# 从源码构建

适合想自己运行、修改或打包 exe 的开发者。

## 环境要求

- **Python 3.10 或更高版本**

## 安装依赖

```powershell
python -m pip install -r requirements.txt
```

运行依赖：

- `charset-normalizer>=3.3.0`（编码检测）
- `ebooklib>=0.18`（EPUB 写入）
- `langdetect>=1.0.0`（语种识别，打包需附带 profiles 数据）
- `pillow>=10.4.0`（封面处理）

## 运行 CLI（无需打包）

```powershell
python -m src convert --input 小说.txt
```

或安装为命令：

```powershell
python -m pip install .
txt2epub convert --input 小说.txt
```

## 打包 GUI 单文件 exe

需要额外安装 PyInstaller：

```powershell
python -m pip install pyinstaller
pyinstaller txt2epub-gui.spec --noconfirm
```

产物在 **`dist/txt2epub-gui.exe`**（单文件，约 23 MB，Windows 64 位）。

> 打包配置 `txt2epub-gui.spec` 已处理：单文件 `-F`、`console=False`（窗口程序）、收集 `langdetect/profiles` 数据、显式声明 tkinter 子模块与 `src` 各子包，确保单文件下能正常运行。

## 运行测试

```powershell
python -m pytest
```
