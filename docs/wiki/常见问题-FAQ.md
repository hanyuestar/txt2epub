# 常见问题（FAQ）

## 转换完成后有文件显示「失败」？

弹出的「转换完成」对话框会列出**失败清单（文件名 — 原因）**。常见原因：

- 文件不是合法 `.txt`（二进制 / 损坏）；
- 文件编码异常且自动检测失败（CLI 用 `--encoding` 指定）；
- 输出目录无写入权限。

单个文件失败**不影响其余文件**，且不会产生残缺 epub。

## 转换出来的内容乱码？

- 优先确认源文件真实编码；CLI 用 `--encoding` 显式指定（如 `--encoding gbk` / `--encoding big5`）。
- v1.0.0 已修复 GBK / GB18030 被误判为韩文编码的乱码问题（见 [编码与兼容性](编码与兼容性.md)）。

## 下载的 exe 双击打不开 / 一闪而过？

- 确认系统是 **Windows 64 位**；
- 可能被杀毒软件拦截，加入白名单后重试；
- 若提示缺少运行库，通常是被拦截或下载不完整，重新从 [Releases](https://github.com/hanyuestar/txt2epub/releases) 下载。

## CLI 报错 “Output file already exists”？

目标 EPUB 已存在且未加 `--overwrite`。确认需要替换时加 `--overwrite`；或换一个 `--output` 路径。

## CLI 报错输入文件必须是 .txt？

`--input` 只接受 `.txt` 文件。请确认文件后缀。

## 章节没有被正确切分？

- 标题格式不在支持列表（见 [章节识别与元数据](章节识别与元数据.md)）；
- 或正文没有明确的章节标题——此时内核会把整本保留为**一个章节**，这是预期行为。

## 封面没有出现在书里？

- CLI：用 `-c / --cover` 指定封面图片路径；
- GUI v1 暂不支持封面，需使用 CLI。

## EPUB 在手机 / 阅读器上排版不好看？

EPUB 是流式排版，字号与行宽由阅读器自适应。可在阅读器内调整字体大小；诗歌 / 预格式化文本转换时加 `--preserve-line-breaks` 保留原换行。
